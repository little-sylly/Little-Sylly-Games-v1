SandboxThe Workshop on a phone

Four frames, each running the real Workshop from v234: the stand-in that ships today, then three phone designs. Try this in each one: paint a part, pick up a sticker, put it on the controller, then Save.

Same in all three

  • The controller stays on screen while a sticker is placed, and a drag on it still turns it (touch-action: none).
  • The sticker surface is still built on the first sticker picked up, never on open.
  • Parts go four across and swatches seven across (~44 px each on a 390 phone); the colour's name moves to the line above the swatches.
  • Sideways, every design splits in two: the controller on the left, its tools on the right.
  • Only the phone tier changes (under 860 px). The 860–1099 pinned layout and widescreen B stay as they are.
