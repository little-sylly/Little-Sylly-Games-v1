# wip/ — the sandbox

Design labs, mock-ups and owner reference material for work in progress. **Everything in here
except this README is git-ignored** (28 Sep 2026): it never reaches GitHub or the deployed site, and
nothing under `js/`, `css/`, `src/`, `data/`, `tools/` or `sw.js` may load from it.

- A lab lives here while its design is being worked out, then is ported into the app by a scripted
  copy (the lobby, jukebox and Workshop rounds are the precedent).
- Once the port ships, the lab moves to the owner's external archive
  (`D:\Coding Projects\Documents archive\`, one dated folder per cleanup, each with a `MANIFEST.md`).
- Because it is untracked, a lab exists on one machine only. If one ever needs to survive a disk,
  copy it somewhere yourself — git will not.

Comments in shipped code that say "ported from wip/…" are history; the folder they name has moved.
