Sandbox, not the shipped app. The "Today (Original)" pane on the left is a faithful, data-driven re-render of the live lobby — same classes (gel-btn lobby-btn), same Fredoka, same brand colours — generated from games.js rather than hand-copied, so it can never silently drift from what it's rendering. It is the fourth layout option, not just a reference. The "Shelves" pane is the redesign — lobby.css + lobby.js, rationale in DESIGN-NOTES.md. The "TV" pane is the same lobby laid out wide for a laptop, tablet or cast screen (a seatless "Big Screen" host mode is reachable via the #tv=host hash — § TV mode in both files, DESIGN-NOTES.md §§ 4-5). This pane is a fixed 900×506 frame for side-by-side viewing only — to judge the real scale, squishing or the eligibility floor, open tv.html directly and resize the window.
