# Little Sylly Arcade — cabinet workshop

This folder is where arcade cabinets get built and play-tested **before** they go into the real Little Sylly Games codebase. The arcade is a secret back door in the suite that opens a menu of small arcade games.

## Files
- `asherplane.js` — Cabinet 01, ASHERPLANE. **Revamped Oct 2026**, built and headless-tested; needs a phone play-test. A toy-bright vertical shmup over a scrolling sea of islands (the old cars/trains-in-space version is kept in `_archive/asherplane-classic.js`). Drag anywhere to fly in 2D (the plane moves as far as your finger moves, so your thumb never covers it); it auto-fires; only a small glowing hit core can be hit. **Five skies, each a clear step up** (`AP_STAGES`: enemy bullet speed, fire rate, Bandit hp, wave pace, dart-shoot chance, and one new Bandit type each), 60 s of Bandits then a unique boss (`AP_BOSS_DEFS`): 1 MORNING — Darts, Swooper formations, Bombers; THE BIG BLIMP (aimed bursts → rings → turret sweeps). 2 MIDDAY — + Copters; THE BUZZ BROTHERS (two giant copters criss-crossing; down one and the other gets mad and adds a spinning spray). 3 SUNSET — + Divers; THE IRONCLAD (a battleship down on the sea — you fly over it; four turrets incl. FLAK shells that burst mid-air; the shuttered bridge opens once they're gone). 4 NIGHT — + Aces (strafe, 3-round bursts, dive out); THE NIGHT OWL (vanishes leaving only its eyes, reappears with HOO HOO!, feather fans, LASER BEAM after a warning line). 5 TWILIGHT — the nightmare: BANDITS BITE BACK (every Bandit shot down lets off a ring of bullets, not from KABOOM or point-blank), lightning, double waves, fewer hearts, a hit only fizzles nearby bullets; THE DREAD BARON (giant crimson triplane: twin guns → spiral + escort Aces → DREAD MODE three-arm reversing spiral). After that it's TWILIGHT 2, 3… forever: the five bosses return in turn, harder every lap (`apLvlFor`). Swooper formations wiped out whole = FORMATION! +500 and a crate; harmless Supply Balloons pop for a crate. Parachute crates: POWER (5 gun levels), SHIELD (soaks one hit), WINGMEN (two helper planes, 15 s), KABOOM (clears the sky), HEART (extra life, max 5). Gold stars build the STAR CHAIN (x2 at 10, up to x5); a missed star breaks it. A hit costs a heart AND a power level. **Play-test warp:** tap the ASHERPLANE title on the start screen to choose the starting sky (shown in pink, session only; remove `apWarp`/`AP_TITLE_HIT` to drop it). Words: TAKE OFF, WARNING! … INBOUND, BLIMP BUSTED!, BROTHERS GROUNDED!, IRONCLAD SUNK!, OWL OUTFOXED!, THE BARON IS DOWN!, IT NEVER ENDS..., MAYDAY!, ACE PILOT!, PAINT YOUR CALL SIGN, TOP ACES, FLY AGAIN. Prefix `ap`; title is `AP_TITLE`. It keeps v1's entry `apStart()`, teardown name `resetArcade()` (what the real engine.js already calls) and the `apLeaderboard` table, so it's still a drop-in for the real game. It follows the house rules (game clock + `apEvents`, no setTimeout).

- `index.html` — the test bench. A lobby that lists every cabinet and stands in for the suite's `showScreen`, `resetToLobby` and `playSecretBeep`. **It must stay self-contained**: every cabinet's code is pasted inline inside it (not loaded with `<script src>`), so it runs anywhere, including the Claude app preview and the phone-test link. When a cabinet's `.js` file changes, update its inline copy in `index.html` too.

- `CLAUDE-OFFLINE.md` — a self-contained copy of these conventions (with code skeletons) for chats where this folder isn't linked. Keep its Status table and rules in step with this file.

## Rules for every cabinet
- **No assets.** All art is drawn in code on a canvas and all sound is `playSecretBeep(freq)`. No image or audio files, no libraries, no CDNs (vanilla JS).
- **Not a Sylly Game.** No multiplayer, no settings, no Sylly Mode. (A purely cosmetic choice, like Chop Salad's fruit-art toggle, is fine.)
- **Short name prefix** on everything global (`ap` Asherplane, `ms` Deep-Sea Sweep (Minesweeper), `ck` Other Side, `sl` Chop Salad, `hj` Cookie Jar, `sto` Stacking Order, `bb` Beyond the Bluff; pick a new one that doesn't clash with these or the suite's game prefixes such as frt, cjar, pko, bld, nt, rtr, gon, pas, gth, cld, dyb, hsg, fyfi).
- **Fixed 360×640 logical canvas**, portrait, letterboxed into its stage. Copy `bbResize`/`msResize` for crisp scaling (identical to `apResize`).
- **DOM:** `screen-arcade-<name>`, a `#<px>-stage` pointer target (touch-action:none) wrapping `#<px>-canvas`, and a `#btn-<px>-exit` button.
- **One RAF loop**, clamped dt, freezes behind `#sound-overlay`, stops when the tab is hidden.
- **Prefer no setTimeout.** Schedule delayed effects against a game clock inside the loop (see `msEvents` in minesweeper.js), so cancelling the loop is the whole teardown.
- **Teardown function** `resetArcade<Name>()`: cancel the loop, clear pointer state. The real game's `resetToLobby()` must call it.
- **A sound map** of moments onto `playSecretBeep` (see `AP_SOUND` / `MS_SOUND`).
- **Menus are drawn on the canvas** and hit-tested against rects. No `<input>` (an iOS keyboard rescales the stage).
- **Session high scores:** top 5, three tap-to-cycle initials, kept in memory only (survive going back to the lobby, cleared on reload).
- **Mobile-first, kid-friendly:** big tap targets, one pointer at a time, keyboard/mouse as a bonus for desktop.

## Adding a new cabinet
1. Write `<name>.js` following the rules above.
2. Add its screen markup and an inline copy of its code to `index.html`, and move it from "Up next" to "Playable" in the lobby.
3. Play-test every state (start, play, lose, win/score, high-score entry, exit) and check the console for errors.

## Building offline
When this folder isn't linked, a chat can build a cabinet from `CLAUDE-OFFLINE.md` (or a handoff that embeds it). It comes back as `<name>.js` plus a one-cabinet `<name>-bench.html`. To bring it in: save the `.js` here, inline it into `index.html` as above, and delete the extra bench page, so `index.html` stays the only bench.
